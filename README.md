# Личный кабинет логистики

Личный кабинет логистики
приложение для сотрудников логистики и колл-центра

Установка:

1. Запустить миграции.
2. Запустить сидер php artisan db:seed --class=NewRegionWarehouseQuoteSeeder. В папке storage/app/public должен
быть файл regions.csv (файл из монолита с маппингом регион->склад и id региона в монолите).
3. Запустить сидер php artisan db:seed --class=QuotesSeeder
4. Запустить сидер php artisan db:seed --class=RegionWarehouseForNewTable. Создаёт новую таблицу
связей для регионов и складов для квот. Это делается из-за того, что неправильно спроектировал таблицу регионов,
не учёл вариант её дальнейшего использования в других частях приложения с гибкими настройками. 
5. Запустить отдельную миграцию php artisan migrate --path=/database/migrations/extra/ для удаления
столбца-связки warehouse_id из таблицы регионов.
